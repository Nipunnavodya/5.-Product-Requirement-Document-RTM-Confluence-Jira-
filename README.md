## 📌 Executive Overview

This repository houses the comprehensive **Product Requirement Document (PRD)** and **Requirements Traceability Matrix (RTM)** for a Next-Gen Mobile Banking Application. Formulated using **Atlassian Confluence** and integrated with **Jira Enterprise**, this project maps business requirements, functional specifications, system security constraints, and user story traceability across 15+ Core User Stories.
